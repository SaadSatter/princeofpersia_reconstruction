# Observation sheet (template)

**Status:** draft kit (T11). Copy this file per session as
`sessions/<session id>-observation.md` (or use a printed copy and transcribe
it unchanged). Never fill in this template itself.

**Rule: observations before interpretation.** During the session the
observer writes only what is seen on screen and heard, with times. Spoken
words go in quotes, verbatim. No "seemed", "felt", "because", "was
confused". Interpretation is written afterwards in a separate section, by
Saad, and labelled with who wrote it and when.

## Event log

Time is the on-screen clock or frame counter (Session B) or mm:ss since the
round start. Event codes are short tags; use several if needed.

Event codes: `UNI` took a uniform · `RIG` rigged a trap · `TRAP` a trap
sprang (on whom, as seen) · `GS` struck a guard · `RS` struck the rival ·
`HIT` lost a heart · `DIS` own disguise broke · `REV` rival revealed on
screen · `NAME` player named a figure aloud · `RUN` / `WALK` / `WAIT` /
`HIDE` movement style · `FLEE` · `STUCK` controls or navigation trouble ·
`BUG` something that looks wrong · `Q` player asked a question.

Motivation columns (G1, `docs/final/GDD.md` section 2): mark only what is
observed.

- `R30`: after the round ended, the player asked for a rematch on their own;
  write the seconds since the end screen (count it only if 30 or less).
- `CA`: in this round the player did something they did not do in the
  previous round, after losing that round; write the tags compared (for
  example "round 1: RUN, GS; round 2: UNI, WALK").
- `RV`: a spoken or visible reaction at a reveal, verbatim ("that was
  you?!", a laugh, a gasp).
- `GL`: gloating after a kill or sprung trap, verbatim.
