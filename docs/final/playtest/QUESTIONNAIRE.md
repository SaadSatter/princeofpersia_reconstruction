# Playtest questionnaire

**Status:** draft kit (T11). Saad approves before the first session.
Asked aloud by the facilitator, who writes the answers in the player's own
words where possible. The player may skip any question. One copy per player
per session; it carries the player code, never a name.

```
Session id:            Player code:            Date:
Session type: A / B    Build commit:           Facilitator role:
```

---

## Part R: after each round (about 1 minute)

Ask before offering a rematch. Repeat for each round.

| # | Question | Answer format | Round 1 | Round 2 | Round 3 | Round 4 |
|---|---|---|---|---|---|---|
| R1 | How tense was that round, from 1 (not tense at all) to 7 (extremely tense)? | 1–7 | | | | |
| R2 | Did you work out which figure was your rival while it looked like a guard? If yes: which one, roughly where, and when (early, middle, late, or the moment)? | Free text, or "no", or "it never disguised as far as I know" | | | | |
| R3 | You struck a guard at [times from the sheet]. For each: why? (a) to take its uniform, (b) I thought it was my rival, (c) it attacked me, (d) by accident, (e) other | One letter per strike, plus words | | | | |
| R4 | How fair did that round feel, from 1 (very unfair) to 7 (completely fair)? What, if anything, felt unfair? | 1–7 + free text | | | | |
| R5 | Would you like to play again right now? | yes / no / maybe | | | | |

The observer separately records whether the player asked for a rematch on
their own, and how many seconds after the round ended (observation sheet
column `R30`). R5 is asked only after that window.

## Part E: end of session

| # | Question | Answer format | Answer |
|---|---|---|---|
| E1 | In a sentence or two, what were you trying to do in the last round? Was that different from the first round? Why? | Free text | |
| E2 | Was there a moment where something surprised you? What was it? | Free text | |
| E3 | (Session B only, before the debrief.) Did your rivals in the different rounds feel like the same opponent or different ones? If different, how? If you had to guess, which round's rival was the more sophisticated program? | same / different / not sure; round number or "can't tell"; free text | |
| E4 | Which round's rival was harder to spot when disguised? | round number / no difference / not sure | |
| E5 | Was anything about the controls or the screen confusing? | Free text | |
| E6 | Anything else you want to tell us? | Free text | |

## Notes for the facilitator

- Read scales with both anchors every time; do not suggest a number.
- R3 needs the guard-strike times from the observation sheet; the observer
  passes them to the facilitator at the end of the round. R3 decides whether
  a guard strike counts as a false identification
  ([`PROTOCOL.md`](PROTOCOL.md) section 3).
- Do not reveal the rival type before E3 is answered.
- In Session A option 2 (human vs human), ask R2 and R3 about the other
  player and mark the round `identification: contaminated`; skip E3 and E4.
