Design:
- **Macro vocabulary** (proposal, matching G1 minus RIG until traps exist): BLEND (walk a guard-like patrol in the current room), DISGUISE (go to the nearest visible downed guard and TAKE), WAIT, FOLLOW (approach the nearest visible figure that the controller currently suspects), STRIKE (draw and attack the adjacent target, or approach it), FLEE (move away from the nearest threat, toward an exit), CLIMB (use the nearest climbable edge or exit up or down). RIG_TRAP is reserved.
- `MacroExecutor`: deterministic; it expands the current macro into per-tick inputs from the seat's observation and legal list only. It queues the next primitive ahead (no idle gap), re-validates every tick, and reports `macro_done` / `macro_failed` with a reason. Targets are chosen by observed attributes only (position, posture, motion, armed), never by ids that distinguish rival from guard.
- `MacroController(policy)`: a `SeatController` that asks a macro policy every N ticks and drives the executor in between. Same interface for the scripted baseline and, later, PPO.
- **Scripted baseline** `VersusBaseline` (a macro policy): disguise from the nearest visible downed guard; otherwise down a lone guard; blend; identify the rival by observed tells only (for example a "guard" that does not react to it, or one off a patrol line); strike when adjacent; flee at 1 heart. It must be competent, not deliberately weak. Document every heuristic in MACROS.md, and say which tells it uses. These must be ones a human could also see.
Acceptance (failing tests first):
1. Determinism: the same seed and controllers give an identical runner result and trace.
2. **Boundary.** The baseline makes identical decisions when a disguised rival is replaced by a real guard with the same observed fields (swap-a-guard test). It never paths toward a rival in another room (it gets only its own observation). No controller code imports `pop.versus` internals or receives the episode.
3. Executor: no motion-null gap between queued primitives while blending (compared with the real guard patrol shape); a failed macro is reported, not looped forever.
4. Competence, on fixed starts with seats swapped, with counts reported: the baseline beats a WAIT controller and a Random controller in most duels (state the numbers you got; do not tune thresholds after looking at held-out starts — only tuning starts, recorded in MACROS.md).
