## 6. Evaluation harness plan (Tech Lead builds; Evaluation Specialist reviews and owns scenarios)

1. **Seat-controller protocol and versus runner** (`pop/seats.py`,
   `pop/versus_runner.py`).
   - Controllers per seat: human, scripted, model, fallback.
   - Each controller receives copies of its own observation and legal
     actions only.
   - Ticks continue while a model call is pending.
   - 5 s timeout, then a labelled `WAIT` fallback.
   - Per-seat call and USD caps; per-seat history and session.
   - Per-seat traces; a seat-swap option.
2. **Macro layer** (CQ-1). The macros: BLEND, DISGUISE, WAIT, FOLLOW,
   STRIKE, FLEE, CLIMB (RIG_TRAP later).
   - Expanded deterministically into the existing inputs.
   - Re-validated every tick.
   - Queues ahead, which avoids the 1-frame tell.
   - Targets figures by visible attributes only.
   - Stale or replaced inputs are counted, which fixes F3.
3. **Versus scripted baseline** (G1: nearest uniform, shortest path, strike
   when adjacent), on the same macros and the same view.
   - It takes the same decisions when a disguised rival is swapped for a
     real guard.
   - It never paths to an unseen rival.
4. **Versus model player.**
   - A new prompt with a version id; the existing provider stack.
   - Prompt tests show no seat, disguise or other-room data.
   - A `--provider fake` dry run; a `--budget-usd` hard stop.
5. **Harness.**
   - Scenario registry (proposals D1 disguise, B2 blend, I3 identify, F5
     fight or retreat; H6 full duel held out; T4 trap after traps exist).
   - Configurations: SvS, MvS, SvM; MvM test-only.
   - Result schema: scenario, starts, seed, commit, model, prompt and config
     version, seat, outcome, termination, invalid and stale actions, calls,
     latency, tokens, cost, fallbacks, trace path, failed runs.
   - Dev, tuning, held-out and release splits kept apart.
6. **Two-seat trace file**, a `--replay` command and a golden replay test.
7. **Deterministic tests in CI** for every item above.
   - The proposed QA list from AUDIT-B, including per-seat limits,
     isolation, stale actions, mutual-death by play, cross-process trace.
   - Live runs never in CI.
8. **Live (paid) runs**, after approval only.
   - Smoke: 1 call, about $0.0001.
   - Minimal pre-G2 suite: about 660 calls, **estimated** $1.9–3.0, cap
     $5.
