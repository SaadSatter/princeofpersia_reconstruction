## What changed from v1

- **The AI rival is a PPO policy we train.** It follows the PR #64 pattern:
  a small learned policy, a facts-only observation, a frozen held-out suite,
  and comparison with scripted opponents.
  - The LLM model player is no longer the rival seat.
  - Live-provider, token and cost fields become N/A for the rival, as in
    PR #64.
  - The paid-call budget is < $1 and only for a smoke test of an LLM
    component, if one is ever built.
  - The rival decides on macro-actions at a fixed cadence: one decision
    every 6 ticks (0.5 s), proposed. G1's 4 s figure came from LLM latency.
    A deterministic controller expands each macro into the existing
    per-tick inputs.
- **Traps are in G2/G3.**
- **Online play is deferred.** G2/G3 is shown locally.
- **Duel limit: 5 minutes** (3,600 frames).
- **Hopping while disguised raises suspicion** (R-V24).
- **Scenario success definitions approved** (D1, B2, I3, F5, H6).
- **Everything stays in this repo for now.**
  - The tracker is `docs/final/TRACKER.md`.
  - The official-repo move uses the midterm method (a snapshot in its own
    folder, a scoped CI workflow, a PR) when Saad says to move.
  - The course deadline for the move is Sat Nov 28.

## Why PPO is feasible here (measured 2026-11-23)

- **Engine speed.** The headless engine runs about 13,700 ticks per second
  with both seats observed: 20 random duels, Python 3.13, one core. At one
  decision every 6 ticks that is about 2,000 decisions per second per core,
  before network cost.
- **Training stack.** It needs only numpy, which is already in the sandbox.
  - Training runs in the orchestrator sandbox.
  - The policy runs in the game in pure Python: a small MLP with weights in
    JSON and a SHA-256 check.
  - So the game, its tests and CI gain **no new dependency**.
  - The training script needs numpy and lives under `tools/rl/`. It is not
    imported by the game.
- **Scale.** This is far below PR #64's 96 M decisions on a GPU, so
  expectations are modest. The held-out comparison is reported whatever
  the result; the model does not need to win.
